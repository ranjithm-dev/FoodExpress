\# 🍔 FoodExpress – Online Food Ordering System



FoodExpress is an online food ordering web application

built using Java, Spring Boot, MySQL, and web technologies.



\## 🚀 Features

\- User Registration and Login

\- Browse Food Menu

\- Add Items to Cart

\- Place Orders

\- Admin Login and Dashboard

\- MySQL Database Integration



\## 🛠️ Technologies Used

\- Java 17

\- Spring Boot

\- Maven

\- MySQL

\- HTML, CSS, JavaScript



\## ⚙️ Setup

1\. Clone the repository.

2\. Configure MySQL.

3\. Set the DB\_PASSWORD environment variable.

4\. Run the Spring Boot application.
